# Nome Limpo Já — site

Arquivos do site prontos para publicação no GitHub Pages:

- `index.html` — página inicial, com o aviso solicitado removido.
- `pagamento.html` — página de detalhes da contratação.
- `logo-nome-limpo.png` — logotipo utilizado nas páginas.
- `banner-promocao.png` — imagem principal da página inicial.

## Publicar no GitHub Pages

1. Crie um repositório no GitHub.
2. Envie os quatro arquivos acima para a raiz do repositório (a mesma pasta).
3. No repositório, abra **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch `main` e a pasta `/ (root)`, depois salve.

A página de pagamento é acessada pelo botão da página inicial. O bloco de pagamento continua sinalizado como configuração pendente; conecte seu checkout/PIX oficial antes de receber pagamentos.
